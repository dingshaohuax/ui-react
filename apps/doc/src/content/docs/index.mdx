## 接下来做什么

<CardGrid stagger>
	<Card title="更新内容" icon="pencil">
		编辑 `src/content/docs/index.mdx`，即可查看此页面的变化。
	</Card>
	<Card title="更改页面布局" icon="document">
		删除 `src/content/docs/index.mdx` 中的 `template: splash`，即可在此页面显示侧边栏。
	</Card>
	<Card title="添加新内容" icon="add-document">
		在 `src/content/docs` 中添加 Markdown 或 MDX 文件，即可创建新页面。
	</Card>
	<Card title="配置站点" icon="setting">
		在 `astro.config.mjs` 中编辑 `sidebar` 及其他配置。
	</Card>
	<Card title="阅读文档" icon="open-book">
		阅读 [Starlight 文档](https://starlight.astro.build/)，了解更多信息。
	</Card>
